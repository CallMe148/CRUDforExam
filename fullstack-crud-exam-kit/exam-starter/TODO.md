# ฝึกสอบ 180 นาที

โค้ด CRUD และหน้าเว็บเขียนครบแล้ว ใช้รายการด้านล่างทบทวนและทดสอบกับ PostgreSQL จริง
ใช้ฐานข้อมูล `exam_practice` แยกจากตัวอย่าง ป้องกันแก้ข้อมูลฝึกของ Book Catalog

| นาที | งาน | เกณฑ์ผ่าน |
|---|---|---|
| 0–15 | อ่านโจทย์ ปรับ schema/env | เชื่อม DB ได้ |
| 15–45 | CRUD categories | GET/POST/PUT/DELETE ผ่าน |
| 45–90 | CRUD books + JOIN | FK ถูก, ไม่พบตอบ 404 |
| 90–115 | Multer | upload ได้, PUT ไม่ส่งปกยังเก็บปกเดิม |
| 115–155 | fetch + FormData + UI | เพิ่ม แสดง แก้ไข ลบทั้งสองตาราง |
| 155–175 | Swagger + ตรวจกรณีผิด | 400/404/409/500 เหมาะสม |
| 175–180 | README + ส่งงาน | clone แล้วรันตามคู่มือได้ |

อ่านคอมเมนต์ใน server.js และ public/app.js ไล่ตามลำดับการทำงาน
หลังทำเสร็จเทียบกับ ../book-catalog ทีละส่วน อย่าคัดลอกทั้งหมดทันที

## เปลี่ยนโจทย์เป็นสินค้า
- categories → product_types, books → products
- title → name, author → brand, cover → image
- แก้ SQL, route, form field, FormData, OpenAPI ให้ชื่อตรงกัน
- ทดสอบลบประเภทที่ยังมีสินค้า ต้องได้ 409
- ฝึกเขียน GET ใหม่โดยไม่เปิดตัวอย่าง

## ตรวจด้วยตัวเอง
1. สร้างหมวดหมู่ แล้วสร้างหนังสือพร้อมปก
2. แก้ชื่อ/ราคาโดยไม่แนบปก ปกเดิมต้องอยู่
3. เปลี่ยนปกและตรวจไฟล์เก่าถูกลบ
4. ส่งราคา -1, ID abc, category ที่ไม่มี, ปกเกิน 2 MB
5. ลบหนังสือ แล้วจึงลบหมวดหมู่
6. ปิด/เปิด server ข้อมูลยังอยู่
